# Recursos de redes y automatización

## Investigación sobre GNS3 y automatización de redes

### 1. ¿Qué tipo de problema podrías resolver consultando la documentación de GNS3?

La documentación de GNS3 puede ayudar a resolver problemas relacionados con la creación y configuración de topologías, instalación y configuración de dispositivos, uso de servidores y solución de errores que puedan presentarse al trabajar con redes simuladas.

### 2. ¿Qué diferencia existe entre la documentación de una herramienta y el repositorio de una biblioteca?

La documentación de una herramienta explica cómo instalarla, configurarla y utilizar sus diferentes funciones. En cambio, el repositorio de una biblioteca contiene su código fuente, versiones, archivos de configuración, ejemplos, problemas reportados y otros recursos relacionados con su desarrollo.

### 3. ¿Qué información revisarías antes de utilizar una biblioteca de automatización?

Revisaría para qué sirve la biblioteca, los requisitos de instalación, las versiones de Python compatibles, los dispositivos o plataformas soportadas, la documentación disponible y ejemplos de uso.

### 4. ¿Por qué es importante comprobar qué plataformas y funciones admite una biblioteca?

Porque no todas las bibliotecas funcionan con los mismos dispositivos, sistemas o versiones. Revisar esta información permite saber si la biblioteca es compatible con nuestro entorno antes de utilizarla y evita problemas durante el desarrollo.

### 5. ¿Cómo podrían utilizarse estos recursos en las siguientes prácticas?

Podrían utilizarse para consultar cómo configurar y solucionar problemas en las topologías de GNS3, además de aprender a utilizar bibliotecas como Netmiko para realizar conexiones y tareas de automatización sobre dispositivos de red.
